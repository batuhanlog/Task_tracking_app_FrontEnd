# 🚀 Task Tracking App - Frontend ✨

📋 Bu repository, proje bazlı kişisel bir görev takip uygulaması olan **Task Tracking App**'in frontend (kullanıcı arayüzü) kodlarını içermektedir. React kullanılarak geliştirilen bu arayüz, kullanıcıların üyesi oldukları projelere özel olarak görevleri görüntülemesine, oluşturmasına, güncellemesine, filtrelemesine ve yönetmesine olanak tanır ve arka uç (backend) API ile sorunsuz bir şekilde etkileşim kurar.

---

## ✨ Temel Teknolojiler & Kütüphaneler

Bu projenin frontend'i aşağıdaki modern teknolojiler kullanılarak oluşturulmuştur:

*   **⚛️ React.js:** Kullanıcı arayüzünü oluşturmak için temel kütüphane.
*   **🔵 TypeScript:** Statik tipleme ile daha güvenli ve sürdürülebilir kod yazımı için.
*   **💨 Tailwind CSS:** Hızlı ve özelleştirilebilir arayüzler için utility-first CSS framework'ü.
*   **🧭 React Router:** Uygulama içi sayfa yönlendirmelerini (routing) yönetmek için.
*   **🔄 React Context API:** Global state yönetimi (kimlik doğrulama, görev verileri vb.) için.
*   **🔗 Axios:** Backend API'ye HTTP istekleri yapmak için kullanılan istemci.
*   **✨ Lucide React:** Şık ve tutarlı ikon seti için.
*   **⚡ Vite:** Hızlı geliştirme ve derleme süreçleri için kullanılan build aracı.
